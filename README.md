# Карманный психолог

Открытая версия приложения «Карманный психолог»: инструменты саморегуляции,
дневник, трекер состояния и тест Сонди.

## Быстрый запуск

Приложение статическое, сборка не требуется:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

Для работы достаточно современного браузера. Все пользовательские данные
хранятся локально в `localStorage` и не отправляются на сервер.

## Структура

- `index.html` — интерфейс приложения.
- `app.js` — основная логика, модули и экспорт данных.
- `diary.js`, `diary.css` — личный дневник.
- `data.js`, `celebrities.js`, `szondi-ito-pavlov.js` — данные и алгоритмы Сонди.
- `styles.css`, `design.css`, `design-dark.css` — оформление.
- `audio/`, `portraits/` — медиаматериалы приложения.
- `android/` — исходники WebView-обёртки для Android.

## Android

В `android/` лежит исходник WebView-обёртки (`MainActivity.java`, манифест и
ресурсы). Это не готовый Gradle-проект: для сборки подключите Android SDK и
соберите APK/AAB самостоятельно. Ключи подписи, пароли и готовые сборки в
репозиторий намеренно не включены.

## Приватность и безопасность

- В репозитории нет ключей подписи, паролей, токенов и пользовательских данных.
- Записи дневника, трекера и результаты теста хранятся только на устройстве.
- Перед публикацией проверьте свои локальные настройки и не добавляйте
  `*.p12`, `*.jks`, `*.keystore`, `.env` и файлы сборок.
