# Android WebView wrapper

`MainActivity.java`, `AndroidManifest.xml` и `res/` — исходник WebView-обёртки.

Приложение использует веб-файлы из корня репозитория. Для сборки:

1. Подготовьте Android SDK и build-tools.
2. Скопируйте веб-файлы (`index.html`, `*.css`, `*.js`, `audio/`, `portraits/`)
   в `assets/` Android-проекта.
3. Скомпилируйте APK/AAB своим обычным способом.

Ключи подписи и пароли в репозитории отсутствуют. Не добавляйте их в git.
